# titanic-kaggle-solution

Ce dépôt contient ma solution pour la compétition classique **Titanic** sur Kaggle. L'objectif est de prédire la survie des passagers en fonction de leurs caractéristiques (âge, sexe, classe, tarif du billet, etc.).

---

## 📌 Contenu du Dépôt

- `titanic_model.ipynb` : Notebook Jupyter complet contenant :
  - **Analyse exploratoire (EDA) :** Visualisation des taux de survie selon les caractéristiques.
  - **Nettoyage des données :** Imputation des valeurs manquantes (`Age`, `Embarked`).
  - **Feature Engineering :** Traitement des variables catégorielles et création de nouvelles variables.
  - **Modélisation :** Entraînement et évaluation d'un modèle de classification.

---

## 🛠️ Outils Utilisés

- **Python 3**
- **Pandas** & **NumPy** pour la manipulation de données
- **Matplotlib** & **Seaborn** pour les graphiques
- **Scikit-Learn** pour la modélisation
